# 📲 Install This Web App

### This isn’t just adding a bookmark to a URL!

Installing this Progressive Web App (PWA) makes it behave like a real app on your device, with its own icon and window. It updates automatically when you reopen it (no app store needed!).

## How to Install

* 🍎 iPhone / iPad (Safari): Tap Share → Add to Home Screen → Add. Enable Open as Web App if shown.
* 🤖 Android (Chrome): Tap ⋮ → Install app (or Add to Home screen).
* 🪟 Windows (Edge/Chrome): Open the ⋯ / ⋮ menu → Apps / Install page as app.
* 🍏 Mac (Safari): Select File → Add to Dock.
* 🐧 Linux (Chrome): Open ⋮ → Install page as app.

Already installed? Just open it from your Home Screen or app launcher. Close and reopen to check for updates!
