# 📲 Instala esta aplicación web

### ¡No es simplemente agregar un marcador a una página web!

Al instalar esta aplicación web progresiva (PWA), funcionará como una aplicación real en tu dispositivo, con su propio ícono y ventana. Se actualiza automáticamente cuando la vuelves a abrir (¡sin necesidad de una tienda de aplicaciones!).

## Cómo instalarla

* 🍎 **iPhone / iPad (Safari):** Toca Compartir → Agregar a pantalla de inicio → Agregar. Activa Abrir como aplicación web si aparece la opción.
* 🤖 **Android (Chrome):** Toca ⋮ → Instalar aplicación (o Agregar a pantalla de inicio).
* 🪟 **Windows (Edge/Chrome):** Abre el menú ⋯ / ⋮ → Aplicaciones / Instalar página como aplicación.
* 🍏 **Mac (Safari):** Selecciona Archivo → Agregar al Dock.
* 🐧 **Linux (Chrome):** Abre ⋮ → Instalar página como aplicación.

¿Ya la instalaste? ¡Simplemente ábrela desde la pantalla de inicio o el menú de aplicaciones! Ciérrala y vuelve a abrirla para buscar actualizaciones.
